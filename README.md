GAME 10033 - 2D Interactive Drawing
Interactive Robot

Name: Zhaoyu Xu


PROJECT DESCRIPTION
This project is a small interactive 2D drawing created using the GAME 10033 2D Game Template.

The drawing is a robot made from multiple primitive shapes, including rectangles, circles, and lines. The robot can be controlled using both keyboard and mouse input.

CONTROLS
Arrow Keys:
- Left Arrow: Move robot left
- Right Arrow: Move robot right
- Up Arrow: Move robot up
- Down Arrow: Move robot down

Mouse:
- Hold Left Mouse Button: Move the robot to the mouse position
- Hold Right Mouse Button: Change the robot body colour to red

Keyboard:
- Hold Space: Change the robot body colour to green

The robot is blue when no colour-change input is being used.
